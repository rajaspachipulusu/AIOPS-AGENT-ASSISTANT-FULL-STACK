# Code of Conduct

## Our commitment

We are committed to making participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume positive intent.
- Accept feedback gracefully.
- Focus on the technical problem, not the person.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without permission.
- Trolling, insulting, or derogatory comments.

## Enforcement

Project maintainers may remove or edit comments, commits, issues, and pull requests that violate this code.
Repeated or severe violations may result in a temporary or permanent ban.

## Scope

This code applies to all project spaces, including issues, pull requests, discussions, and related communication channels.

## Reporting

Report unacceptable behavior to the project maintainer.
All reports will be reviewed and handled fairly and confidentially.
